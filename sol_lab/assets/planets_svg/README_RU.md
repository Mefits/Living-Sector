# Векторный пилот Sol Lab

Три редактируемых SVG-исходника: `sol/earth.svg`, `sol/saturn.svg`, `biomes/desert_world.svg`.
Каждый состоит исключительно из геометрии SVG (ни одного встроенного PNG). Земная суша обведена по оригинальному рисунку с упрощением контура; Сатурн и пустынный биом нарисованы отдельными заливками, дугами и путями.

Для игры заранее экспортированы две PNG-версии для каждого:
- `assets/planets/{sol,biomes}/map_icons/*_vector.png`: **32×32**, дальний план;
- `assets/planets/{sol,biomes}/planets/*_vector.png`: **512×512**, приближение.

Для повторного экспорта после редактирования SVG:

```bash
pip install cairosvg
python sol_lab/tools/export_planet_vectors.py
```

`PlanetSprites.texture_for` отдаёт пилотные PNG только для ключей `sol/earth`, `sol/saturn`, `biomes/desert_world`. Остальные 18 типов используют прежние PNG; для отсутствующих пилотных PNG предусмотрен автоматический возврат к исходным текстурам. `visual_biome` позволяет выбрать `desert_world` в другой системе без изменения симуляции.

В Godot SVG по умолчанию импортируется как растр; именно поэтому SVG — авторские исходники, а игра берёт готовые PNG и не тратит время на динамическую векторизацию. Оригинальные изображения оставлены для сравнения и отката.
