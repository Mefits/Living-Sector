# Векторный пилот Sol Lab — масштабируемые планеты

SVG-исходники (редактируемая геометрия, без встроенных PNG):
- `sol/earth.svg` — Земля со сглаженной береговой линией (кривые Безье);
- `sol/saturn.svg` — Сатурн с кольцами;
- `biomes/desert_world.svg` — универсальный пустынный биом.

## Как выводятся планеты в Godot 4.7

`scripts/view/planet_sprite_catalog.gd` использует **DPITexture**, создаваемый
из встроенных исходных SVG-строк через `DPITexture.create_from_string()`.
Это важно: Godot 4.7 по умолчанию импортирует SVG как обычный растр, а в сборке
Windows оригинальный SVG может отсутствовать. Поэтому отдельный сгенерированный
`scripts/view/planet_svg_sources.gd` содержит их векторные исходники и
работает независимо от настроек импорта. Размер растра выбирается один раз
при смене масштабного диапазона, а не на каждом кадре:

| Видимый размер изображения на экране | Разрешение |
| --- | --- |
| до 512 физических пикселей | 512×512 |
| 513–1024 пикселя | 1024×1024 |
| 1025–2048 пикселей | 2048×2048 |
| более 2048 пикселей | 4096×4096 |

Параметр — **диаметр всей текстуры**, с учетом колец Сатурна и UI scale,
а не значение приближения камеры. Невидимые за экраном планеты не запрашивают
дорогостоящие 2K/4K текстуры. Кеш хранит не более шести вариантов SVG;
при освобождении и повторной загрузке допускается единичный пересчет.
Изображение **не** векторизуется заново на каждом кадре.

Орбиты, клики, физика кораблей, здания и экономические механики не изменены.

- На далеком масштабе: ранее экспортированный значок 32×32.
- На среднем/ближнем: импортированный SVG как DPITexture подходящего размера.
- Если SVG-путь недоступен: резервный `*_vector.png` (512×512).
- Остальные планеты и биомы: прежние PNG без изменений.

## Вспомогательный экспорт PNG

Исходники прежних миниатюр/PNG оставлены в `assets/planets/`.
**После правки SVG нужно регенерировать их встроенные исходники**, иначе
игра продолжит использовать предыдущую версию:

```bash
python sol_lab/tools/embed_planet_svg_sources.py
```

Для экспортов резервных PNG (не требуются для векторного приближения):

```bash
pip install cairosvg
python sol_lab/tools/export_planet_vectors.py
```

Для проверки логики в Godot:

```bash
godot --headless --path sol_lab -s res://tests/sol_planet_vector_pilot_check.gd
```

Это лишь пилот для трёх объектов. Остальные биомы не переведены в SVG.
