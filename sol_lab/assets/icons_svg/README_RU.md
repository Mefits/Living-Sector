# SVG-версии исходных иконок и зданий Living Sector

Источник: архивы `Living-Sector-Resource-Icons(2).zip`, `Living-Sector-Building-Sprites(2).zip`.
Переведены 13 ресурсов и 7 построек, без генерации новых дизайнов.

SVG состоит из многоконтурных векторных `path` без embedded PNG.
Геометрия автоматически получена из оригинальных PNG 64×64;
палитра упрощена до 12 цветов, мелкий шум отфильтрован.
Из исходного маленького PNG нельзя восстановить невидимые детали,
поэтому результат близок по силуэту, но не идентичен пиксель-в-пиксель.

`assets/icons/sol_icons_vector_{20,32,64}.png` — готовые композитные
атласы с той же раскладкой и ID, что у прежних атласов.
`assets/icons/vector_large/buildings/*.png` — 256px экспорты для крупных
построек на поверхности при приближении, без перерасчета SVG каждый кадр.

Старые `sol_icons_20/32/64.png` оставлены без изменений для отката.
Для повторной векторизации см. приложенный архив с исходниками и README.
