# Living Sector: station asset production list

Three station cores T1–T3, sixteen standalone module assets and three slot-state assets. All images are editable 64×64 flat SVG files with transparent backgrounds, restrained functional colors, no glow or bevel. Recombine visually without producing static images for every station loadout.

The images for future module classes (habitat, research, defense, etc.) are placeholders only; the live Observer reads actual facility and construction-site data, not these artwork files. T1/T2/T3 are a provisional visual layout and not a simulated upgrade rule. The Canvas renderer currently draws compatible flat vector shapes directly for clickable modules and smooth zoom.

See [manifest.json](manifest.json) for file-by-file list. No binary font assets are bundled.
