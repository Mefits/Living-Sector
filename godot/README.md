- **[Текущий прогресс: 100 пунктов](docs/MIGRATION_TRACKER_RU.md)** — единственный живой список задач, статусов, препятствий и доказательств. `CODE_UNVERIFIED` не считается завершением.
- **[Исчерпывающий реестр исходников](docs/SOURCE_INVENTORY.json)** — 793 файла замороженной Rust-версии с git-хешами; нет молчаливых исключений.
- **[Контракт поведения при переносе](PORTING_CONTRACT.md)** — точный перенос правил, ресурсов и физических квитанций, а не игра по мотивам.

> Исходная **Rust Galaxy 0.6.7 заморожена** в `archive/rust-galaxy-067-reference`. В Godot P0 пока только каркас и чтение данных; игровой запуск Godot ещё не проверен.


**Статус: первый запускаемый каркас, НЕ новая версия полноценной игры.**

Godot 4.x (совместимая ветка 4.3+), GDScript, без Rust, без C#, без компиляции
при обычных изменениях. Файлы игры — обычные сцены и скрипты Godot.

Откройте `godot/project.godot` из корня полного репозитория в Godot Editor
и нажмите F6/F5. Первое окно должно прочитать **существующие** JSON-данные
из соседней `native/priv/galaxy/data` и показать карту восьми систем
и сведения о телах. Это **проверка структуры Godot и импорта настоящего
датасета**, а не симуляция кораблей, рынков и производственных цепочек.

До экспорта автономной игры данные надо будет копировать в `godot/data/galaxy`
с автоматической проверкой соответствия оригиналам. Скрипт уже умеет
сначала искать файлы там, затем в исходном native/ каталоге.

Дальнейший перенос идёт **по исходникам**, см. `PORTING_CONTRACT.md`.
Rust-ветка `archive/rust-galaxy-067-reference` не изменяется.
Никакого GitHub Actions, постоянных сборок и ложных отчётов об экономике.

## P0 — интерактивная карта и бесплатный локальный запуск

- [Актуальный P0-блок](https://github.com/Mefits/Living-Sector/tree/feature/godot-p0-world-inspector-and-audit/godot).
- Для Windows скачайте **Standard Godot 4** (не .NET), положите исполняемый файл как `godot/Godot.exe` или задайте переменную `GODOT_EXE`. Это движок, а не Rust-компилятор.
- Запустите **`godot/UPDATE_AND_PLAY.cmd`**. Если это Git clone на рабочей ветке без несохранённых изменений, скрипт сделает только `git pull --ff-only`. Если файлы распакованы из ZIP без `.git`, текущая версия запустится без автоматического обновления; обновляйте ZIP самостоятельно. Чужие изменения автоматически не стираются.
- Для CLI-проверки в установленном Godot: `godot --headless --path godot --script res://tests/p0_seed_check.gd`. Ожидаем `P0_SEED_PASS` и код 0, но **в данной среде Godot не установлен, запуск пока НЕ подтверждён**.
- Если возникла ошибка, нажмите **`godot/SAVE_DIAGNOSTICS.cmd`** и пришлите созданный `diagnostics-*.zip`. В архиве только локальный лог Godot и SHA исходников, без сохранений.
- [Матрица разных исторических исходников](docs/ROOT_TREE_DELTA_RU.md): 132 уникальных/отличающихся файла; не удалены и ждут содержательного решения.
- [Правильный выбор стартового мира](docs/WORLD_SOURCE_POLICY_RU.md): Galaxy = 8 систем, 3 фракции; остальные сценарии отдельно.
- [Проверенная структура исходных JSON](docs/P0_SEED_AUDIT.json): 8 систем, 47 тел, 15 объектов, 24 корабля, 3 рынка; это **проверка данных**, не доказательство запуска Godot.

**Дальше:** завершить Godot P0 на ПК и перейти к фиксированным тикам/сохранениям P1. Никаких денег GitHub Actions, не создаём симуляционных контрактов, которых ещё нет в Godot.

## Использовать возможности Godot до написания собственного кода

Перед каждым следующим игровым блоком читать:
- [Технологии и плагины по каждому этапу P0–P10](docs/GODOT_TOOLING_DECISIONS_RU.md) — варианты, ограничения, решение о внедрении.
- [База знаний по геймдеву](docs/GAMEDEV_KNOWLEDGE_BASE_RU.md) — документация, справочники алгоритмов, паттерны и таблица «симптом → готовый приём».
- [Сглаживание движения и независимые тики](docs/SMOOTH_MOTION_RU.md) — как убрать jitter кораблей без ложных перемещений экономики.

**Кандидаты:** GUT для коротких тестов; LimboAI/State Charts для BT/FSM после измерений; Phantom Camera для сложного слежения; TauPlot для продвинутых графиков. **Ни один addon ещё не установлен.** Сначала использовать штатные CanvasItem/Camera2D/GraphEdit/MultiMesh, проверять версии и экспорт Windows.
