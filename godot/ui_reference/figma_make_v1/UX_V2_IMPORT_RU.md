# Figma Make UX v2 — интеграция в SystemBalance (18.11.2026)

**Источник:** архив `Living Sector Game Interface.zip`, файлы
`src/App.tsx` (~92 КБ) и `src/index.css` (~46 КБ).
Пользовательский прототип обновлён в
https://www.figma.com/make/ecvrssCEMaMqUObXlDkLzN/Living-Sector-Game-Interface

## Что реально перенесено в нативный Godot

Используется существующая Theme/LSComponents и живые данные экономики,
без подмены объектов симуляции. Сокращённые наборы вкладок в
`scripts/view/strategy_workspaces.gd` соответствуют `workspaceTabs`
из обновлённого `App.tsx`:

| Экран | Изменённая структура Godot |
|---|---|
| Колония | **Сводка**: состояние/население, проблемы, объекты, решения, ключевые рыночные запасы, стройки, локальные суда и ссылки |
| Предприятие | **Процесс и снабжение** / **Труд и склад** |
| Экономика | **Рынок и цепочки** / **Дефициты и узкие места** |
| Строительство | **Проекты и снабжение**: реальный прогресс, рынок материалов, переход к перевозкам, причины блокировок |
| Флот | **Рейсы и контракты** / **Грузы и стыковка** |
| Управление | **Цели и задачи** / **Объяснения** — только опубликованные данные |
| Исследования | **Текущая программа**: прогресс и доступные предпосылки/открытия |
| Отдельный корабль | Существующий экран **Обзор / Груз / Маршрут**, сохранён |

- `canonical_tab()` переводит старые локальные ссылки, названия вкладок и
  псевдо-ID прототипа (`overview`, `chains`, `cargo`, `priorities`)
  в новые маршруты.
- `strategy_ui.gd` хранит нормализованные вкладки в истории
  переходов, корректно переключает выбор объекта и кнопку «Назад».
- Для объекта N151 `station` с `body_id` и адресом
  `<body_id>-colony` экран/список показывают **Административный центр**,
  а `construction_dock` — **Строительный док колонии**.
  Это **только презентация**, тип N39/save-файла не меняется.
- Старые значения «Обзор», «Запасы», «Контракты» и другие остаются
  действительными внутренними маршрутами через alias mapping;
  не создаются пустые вкладки.

## Что намеренно НЕ перенесено

- Любые `DEMO` ресурсы, деньги, статусы, даты/циклы, FPS/SIM/UI,
  150 млн жителей, `LS-044`, «Завод Вектор», скорости, ETA, сплавы,
  демонстрационные решения и объяснения ИИ.
- Подставные темпы производства, сроки, прогнозы дефицитов.
  Неизвестные показатели остаются `—` или имеют понятное
  объяснение «данные ещё не доступны».
- Изменения N39/N151/N14/N158, орбитальной механики, строек и
  генерации миров — этот PR только про представление данных и переходы.
- **Пиксельная приёмка 1:1** не подтверждена. Архив послужил исходником
  компоновки; точную геометрию и поведение на Windows нужно проверить
  отдельным запуском Godot 4.7.2 на экранах 1920×1080 и 1366×768.

## Следующие визуальные улучшения после проверки

1. Сравнить Godot со свежим Make по сетке, высоте строк и состояниям
   окон, не трогая карту/орбиты/HUD.
2. Исключить переполнение и тяжёлую вертикальную прокрутку у колоний
   с большим числом производств; использовать реальную фильтрацию.
3. Подключать дополнительные данные ИИ/исследований только после
   появления их в авторитетном снимке мира.
