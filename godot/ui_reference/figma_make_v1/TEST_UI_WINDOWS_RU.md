# Проверка интерфейса Figma → Godot на Windows

**Ветка:** `feature/SystemBalance`. **Не** `perf-astra-5` — эта ветка содержит текущую реализацию нового интерфейса, а не объединение независимых воркеров оптимизации.

## 1. Подтянуть ветку

В PowerShell, из корня Living-Sector:

```powershell
git fetch origin feature/SystemBalance
git switch feature/SystemBalance
git pull --ff-only origin feature/SystemBalance
```

Если ветки ещё нет локально: `git switch --track origin/feature/SystemBalance`. При несохранённых локальных изменениях сначала коммитьте или сохраните их отдельно — не используйте `reset --hard`.

## 2. Запустить игру с короткой проверкой интерфейса

```powershell
powershell -ExecutionPolicy Bypass -File .\godot\tools\launch_ui_review.ps1
```

Скрипт ищет Godot 4.7.2 по ранее указанному пути `D:\PROGRAMS\Godot_v4.7.2-stable_win64.exe\`, либо в PATH. Можно передать явный `-GodotExe "D:\...\Godot.exe"`.

Перед графическим запуском он выполняет только два небольших UI-теста без симуляции тысяч тиков: контракт Theme и структуру реальных Control-окон. Если любой тест падает, графический запуск прекращается и ошибка остаётся в консоли. Передайте весь текст ошибки. Чтобы сразу открыть игру без проверок: добавьте `-SkipSmoke`. Только проверки: `-SmokeOnly`.

## 3. Проверить визуально

Сравнивайте с [оригинальным Figma Make V1](https://www.figma.com/make/ecvrssCEMaMqUObXlDkLzN/Living-Sector-Game-Interface) на **1920×1080 и 1366×768**, если доступны оба разрешения. Исходные React/CSS лежат в `godot/ui_reference/figma_make_v1/`. Настоящие изображения экрана Figma в этот GitHub-снимок пока не включены.

Пройдите через колонию, предприятие, экономику, строительство, флот, управление и исследования. Проверьте: верхние шесть ресурсов, работу паузы/×1/×16, левое меню, узкий правый аутлайнер (скрытие/возврат), переходы между вкладками и обратно, выбор объектов, фильтр и очистку поиска, горизонтальную прокрутку таблиц, вертикальную прокрутку страниц, всплывающие сигналы, сохранение и загрузку.

Смените масштаб UI, проверьте свёрнутую боковую панель на небольшом окне, затем полноэкранный режим. Все числа должны приходить из текущей симуляции N39/N14/N153. Отсутствующее значение показано `—`, а не фальшивыми данными макета.

## Что пока не утверждается

Кодовая реализация этапов 1–6 зафиксирована, но **ни тесты Godot, ни визуальное сравнение здесь не выполнялись**: в рабочем окружении разработки нет Godot. Поэтому первый запуск в Windows — это реальная приёмка, а не повтор уже успешной проверки. Отправьте скриншот окна и консольный лог при проблемах. Не переносите патчи в оптимизационную ветку до подтверждения работоспособности UI.
