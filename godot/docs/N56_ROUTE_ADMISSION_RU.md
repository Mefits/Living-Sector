# N56 — проверка допуска маршрута без изменения мира

Источник: frozen Rust `crates/sim_core/src/agents/ship/mod.rs`, функция `route_actions`; Godot `route_graph.gd`, `ship_transit.gd` (N40). Rust допускает fallback `Travel` при отсутствии маршрута. В Godot такой fallback **не разрешён** до переноса его физической семантики. Это сознательная ограничительная политика, не полное Rust parity.

Три части: (1) единственное направленное ребро, (2) реальные конечные координаты `Vector2` без интерпретации `travel_routes.distance` как физического расстояния, (3) атомарная read-only проверка последовательности ног. Никакого изменения положения корабля, топлива, денег, груза, стыковки или календаря.

Зависимости: `route_graph.gd` интеграционной базы; при последующем подключении к N40 следует проверить прямой вызов `depart` и запретить обход допуска. Пока это независимый адаптер, **не live-world integration**.

Тест: `godot --headless --path godot --script res://tests/n56_route_admission_check.gd`. Проверяет однонаправленность, отсутствие ребра, недостающие позиции, нулевую дистанцию, две ноги и отсутствие побочных изменений. При отсутствии Godot статус CODE_UNVERIFIED. Лицензии: только штатные Godot RefCounted/Vector2/Dictionary, новых библиотек и ассетов нет.
