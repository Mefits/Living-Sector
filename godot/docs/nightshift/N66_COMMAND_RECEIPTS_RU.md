# N66 — подтверждение уникальности команд кораблей

**Статус: CODE_UNVERIFIED.** Ветка поверх N64 (#153), не затрагивает P1/main/stable/Rust или N39 production.

- `native_command_receipts.gd` — единая таблица `operation_id → canonical JSON fingerprint + request + result` для четырёх явных команд: `dock`, `undock`, `depart`, `depart_itinerary_hop`. При повторном *идентичном* запросе возвращается прежний receipt без выполнения действия; несовпадение аргументов под тем же ID отвергается. Отрицательные ответы также сохраняются для стабильной семантики retry после reload. Фактическая бизнес-операция исполняется исключительно имеющимися N57/N21/N14 властями, не вторым кошельком или маршрутизатором.
- `native_itinerary_runtime.gd` N64 теперь содержит `commands` и `execute_command(...)`. Полный memory-only checkpoint дополнен обязательным доменом `command_receipts`, версия изменена с 1 на **2**. Restore проходит все проверки **до публикации** нового runtime; старое состояние без receipts не выдаётся за полноценное.
- `tests/n66_command_receipts_check.gd`: реальный native seed, explicit dock→undock→depart, повторы на том же и на восстановленном in-memory состоянии, стабильный N14 transit token, запрет смены команды под одним ID и подделанных receipt при корректно пересчитанном внешнем SHA.

Не подключено автоматически к P1; не покрывает N39 производство/контракты/фоновые команды ИИ. Godot не запускался: тест лишь подготовлен. Пользователь будет тестировать после полного переноса, отдельно ничего запускать не требуется.
