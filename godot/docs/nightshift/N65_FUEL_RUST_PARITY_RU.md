# N65 — точная семантика топлива Rust Galaxy 0.6.7

**CODE_UNVERIFIED.** После сверки frozen `native/crates/sim_core/src/agents/ship/mod.rs` и `agents/ship/actions.rs` обнаружено существенное расхождение: в Rust `advance_transits` **продвигает корабль даже при нулевом топливе**, затем списывает топливо с `max(0.0)`; `Travel` не имеет обязательной проверки полного бака. Старый Godot `ship_transit.gd` останавливал полёт с `out_of_fuel` и не принимал отправление с 0 топлива. Это не паритет.

## Реализация
- `ship_transit.gd`: устранён искусственный hard-stop при нехватке топлива; по исходным формулам Rust продвижение и clamp топлива выполняются независимо. Негативный/NaN fuel по-прежнему fail-closed.
- `ships/native_fuel_diagnostics.gd`: read-only источник топлива/расхода и признаков `depleted_at_location`, `depleted_in_transit_but_moving`. **Никакой фиктивной эвакуации, дозаправки, ремонта или остановки корабля**.
- `tests/n65_zero_fuel_rust_parity_check.gd`: берёт настоящий frozen seed, явно переводит шахтёра в тестовое состояние 0 топлива, подтверждает разрешённый вылет, движение, отсутствие эмиссии топлива, сохранение/восстановление N54.

Ветка от N61, изолирована от N39 production, P1, main/stable. Godot binary не использовался, тест не запускался. Нужна интеграция этой важной поправки в общий transit при объединении остальных PR.
