# Резервации ночных блоков

**Не создавайте N1.json…N8.json заранее.** Они появятся в момент реального начала разработки конкретным чатом.

Каждый чат обязан выполнять протокол из [CLAIM_PROTOCOL_RU.md](../CLAIM_PROTOCOL_RU.md): создать `Nx.json` со статусом `IN_PROGRESS` **перед** началом работы и только после успешного создания переходить к исследованию/коду. **Вторая сессия проверяет наличие claims в общей ветке**, не создаёт второй PR на тот же блок.

Статусы CLAIM: `IN_PROGRESS`, `BLOCKED`, `CODE_UNVERIFIED`, `VERIFIED` (последний только по настоящему тесту). Заполненный финальный claim остаётся в истории.
