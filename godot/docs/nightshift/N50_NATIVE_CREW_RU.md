# N50 — агрегированные экипажи стартового флота Godot

**Статус:** CODE_UNVERIFIED (код и headless-тест написаны; Godot 4.7 здесь не установлен). Родитель — N46 / PR #136. Все 24 стартовых корабля из замороженного Rust Galaxy 0.6.7.

## Источник фактов

- `native/crates/sim_db/src/spawner.rs`: для ShipCrew fresh/default: hunger=10.0, morale=70.0, fatigue=10.0, health=100.0, wages_credits=0 (если нет сохранённого resume), task=Idle.
- `native/crates/sim_core/src/agents/ship/components.rs`: агрегированное состояние экипажа **на один корабль**; `ShipCrewSkills::for_roles` начинает с navigation/engineering/trading=30, combat=20, прибавляет +10 за pilot/engineer/trader соответственно (cap 100). Производная эффективность `health/100 * 0.6 + morale/100 * 0.4`, clamp 0.1..1.0.
- `native/crates/sim_core/src/simulation/config.rs`: шестёрка ship class, точный crew_size и массив ролей. 3 симметричные фракции × 8 кораблей = 24 корабля, **123 агрегированных члена экипажей**.

## Изменения и границы

- `scripts/sim/ships/native_crew_roster.gd` — data-only `RefCounted`, не создаёт сотни тяжёлых SceneTree nodes и не потребляет ресурсы/деньги. `initialize_new_game` принимает только неизмёненное свежее `ShipState` с полными баками/пустыми трюмами, верными class roles и без полёта. Повторный вызов запрещён.
- `snapshot()` сортирует ID и копирует записи. `restore(records,fleet)` атомарно валидирует все 24 ID, типы, роли, навыки и диапазоны; восстановленная мораль/усталость/деньги экипажа не меняются.
- `efficiency(ship_id)` реализует формулу Rust. Никакой зарплаты не начисляется и не переводится, задачи экипажа не симулируются. Это начальное состояние и безопасный формат отдельных данных, не обещание полноценного ИИ.
- `tests/n50_native_crew_roster_check.gd`: сверяет 123 человека, точные навыки майнера/тяжёлого грузовика, начальную эффективность 0.88, повторный старт, replay snapshot и отклонение искажённых полей без мутации.

## Для общей интеграции

Текущая P1-игра остаётся неизменной, этот PR — отдельный opt-in компонент поверх N46. Нужны согласованные единые TickRunner и атомарный world+ship+crew save. Соседний N39 production принадлежит другому агенту, его файлы не редактировались. **Не просить пользователя запускать отдельные тесты N50**; приёмка общим ZIP после 20–30 блоков.
