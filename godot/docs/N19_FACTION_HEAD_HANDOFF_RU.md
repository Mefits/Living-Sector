# N19 — Фракционный Глава: арбитраж и выдача грантов

Статус: **CODE_UNVERIFIED**. Код не исполнялся в Godot Runtime.

## Источники и границы
Rust эталон `native/crates/sim_core/src/strategy/coordination.rs`: единый глава сравнивает готовые предложения администраторов, не выделяет более одного нового финансируемого проекта за цикл; кризис жизнеобеспечения приоритетнее мирной экспансии; смена стратегии требует подтверждения двух циклов, кроме экстренного решения; активный оплаченный план нельзя прерывать новым грантом. Rust `agents/faction.rs`: `FACTION_SUBSIDY_FLOOR = 5000` CR. Полный `options.rs` и `director.rs` ещё НЕ портированы.

## Реализация
`scripts/sim/strategy/faction_head.gd` — чистый `RefCounted` арбитр, без SceneTree, AI-нод и записи в склады/казну. Получает только **реальные подготовленные native-предложения** (supply/research/expand/migrate): действие, цель, оценку, доступность, стоимость, полномочия. Ничего не придумывает при отсутствии источников. Проверяет бюджет после резерва 5000 CR, кризис, режим полномочий, уже выданный приказ/активный физический план. Стабильная сортировка, двухцикловый hysteresis, exact-match грант с максимальной стоимостью и запретом повторного решения одного тика. Сохраняет и восстанавливает память и последнее решение. Грант — **не платёж и не контракт**; исполнителю необходима повторная проверка ledger, маршрута, escrow и склада.

## Архитектура
Штатные Godot GDScript/Dictionary/RefCounted достаточны для единиц Глав фракций; LimboAI/State Charts не подходят как обязательная зависимость для стратегического сравнения, а Node-per-ship не нужен. Паттерны Game Loop/Command/State и сохранение детерминизма; реализация не заменяет native HTN, который должен исполнять уже выбранную цель.
