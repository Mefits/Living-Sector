## Правила переноса

1. Не переносить бинарные ассеты автоматически из Rust в `godot/`. До подтверждения прав — использовать встроенные примитивы Godot, собственные SVG и системный fallback-шрифт.
2. Для каждого переносимого ассета фиксировать исходный URL/автора, конкретную лицензию/версию, разрешённые виды распространения и обязательные attribution/notice, затем отдельным ревью изменять `godot_transfer` на разрешённый статус.
3. Не считать существование файла в открытом GitHub-репозитории разрешением на его распространение в новой сборке. Для музыки и моделей особенно важны оригинальные лицензии и источники.
4. Godot 4 уже предоставляет CanvasItem, draw primitives, Label и AudioStreamPlayer; сторонние пакеты и ассеты не требуются для базового P0 UI. Новых зависимостей нет.

## Воспроизводимая проверка

Из полного Git checkout выполнить `python godot/scripts/n37_audit_assets.py`. Скрипт сравнивает 97 путей, Git blob SHA и размеры с замороженным commit, проверяет полноту категорий и запрещает нерассмотренные transfer approvals. Возвращает код 0 только при точном совпадении манифеста; **не** подтверждает лицензионную чистоту или запуск Godot. Требует доступного локально объекта эталонного коммита; в shallow checkout может завершиться кодом 2.
