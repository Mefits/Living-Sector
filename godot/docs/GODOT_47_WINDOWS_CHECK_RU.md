# Living Sector N32 — проверка на Godot 4.7.2 Standard (Windows)

## Что изменено

- `project.godot`: минимальная требуемая версия движка повышена с 4.3 до 4.7; сохранены прежние настройки рендера GL Compatibility и соотношение сторон окна (`keep`), чтобы не изменить внешний вид при переносе.
- `RUN-INTEGRATION-SMOKE.cmd`: исправлена передача пути `--path` без завершающего обратного слеша; сохраняются `project-import-console.txt` и `*-console.txt` (stdout/stderr) даже при отказе Godot до создания обычного `--log-file`. Записывается версия Godot.
- `scripts/save_diagnostics.ps1`: архивирует обычные журналы N32, консольные журналы и `summary.txt`. Ранее получался архив только с `manifest.json`.

## Запуск без Git

1. Использовать полный исходный архив интеграционного кандидата N32 (не только папку `godot`), включая `native/priv/galaxy/data`.
2. Скопировать три обновлённых файла поверх соответствующих файлов в `godot/`.
3. Исполняемый файл Godot 4.7.2 **Standard** положить в `godot/Godot.exe`.
4. Запустить `godot/RUN-INTEGRATION-SMOKE.cmd` двойным щелчком. В окне появится версия движка, затем результат быстрого прохода из 11 тестов.
5. Запустить `godot/SAVE_DIAGNOSTICS.cmd` и приложить `godot/diagnostics-*.zip`. Логи доступны и вручную в `godot/logs/integration`.

**Статус:** изменение исходников и инфраструктуры для Godot 4.7.2; настоящая проверка GDScript parser/runtime пока **не выполнена** на Windows. Прежние 11 FAIL вызваны некорректным Windows CLI path, а не подтверждёнными ошибками механик. Перед объединением PR нужны новый лог импорта, тесты и ручной запуск F5.

Отдельные модульные тесты не доказывают полной интеграции экономики, торговли и ИИ в `TickRunner`.
