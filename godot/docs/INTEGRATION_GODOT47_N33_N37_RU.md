## Правила следующего этапа

1. До подтверждения игрового запуска не объединять с `main` и не подменять проверенную P1.
2. Следующий разработчик получает **одну GitHub ветку**, не пачку маленьких ZIP и CMD.
3. Сначала интегрировать реальный источник кораблей, склада, контрактов и кошельков в единую авторитетную модель; только после этого opt-in N35 может быть включён для всех нужных игровых тиков.
4. При подходящей среде автоматически запускать краткую проверку и Godot parser; пользователь не должен переносить патчи по одному файлу.
5. Параллельный ещё работающий агент остаётся владельцем своей ветки; изменения из его будущих PR переносить отдельно после проверки актуального diff.
