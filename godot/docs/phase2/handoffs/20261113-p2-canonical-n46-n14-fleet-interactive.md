**Единая ветка:** `integration/godot-phase2-unified-20261113`, один PR #249, Gate 2 **частично интегрирован на уровне кода**. Авторитетный N158/N39 TickRunner и N9 ledger НЕ дублировались. GitHub Actions / Windows export **НЕ запускались**.

## Изменённая работающая вертикаль по исходникам

1. `n158_galaxy_production_seed.gd` теперь вызывает существующий source-validated `N46 NativeFleetBootstrap.build_new_game(seed)`; читает **ровно 24 исходные записи** (по 8 из Sol, Alpha Centauri и Nadir), выносит их реальный class/faction/location, N46 полные class-specific Fuel, пустые Cargo и точные исходные Credits в `projected["ships"]`. Идентификаторы — стабильные registry ordinal `@system-sol/N` и аналоги; не выдуманные Rust UUID.
2. `n39_native_world_schema.gd`: optional для *legacy* snapshots, для нового мира строгая проверка Fleet через N13 ShipState.restore, невозрастающих? нет — строго положительный ship_next_token и строго больше активных transit tokens; `ship:<id>` wallets включены в **Единственный** N9 Ledger на самом первом `initialize`. Балансы сохраняются рядом с денежным состоянием станций/населения; второй ship ledger не создаётся.
3. `unified_ship_phase.gd` — pure per-tick N14 stage. Уже существующий `ShipTransit.depart/advance` применяет оригинальную directed route graph, настоящие moving station/body positions от N43 NativeLocationResolver, fuel consumption, transit token. Idle ships не двигаются без реальной команды: **никакого фальшивого AI**. По прибытии system_id обновляется от source-принадлежности destination. `n39_native_world_production.gd::apply_ship_phase` применяет только одобренную структуру ship/nonce и отвергает изменение Credits, Cargo, spec и любых других счетов; единственный atomic N39 World swap.
4. `n158_production_runtime.gd` теперь исполняет один `ships` stage в source NATIVE_PHASE_ORDER (после orbital bodies, перед paid facilities), используя текущий clock и тот же world. Публичное `request_ship_departure(id, destination)` — строгая ручная команда/будущая dispatcher interface, а не автономный behavior tree. Публичный `fleet_snapshot()` read-only; `implemented_phases()` теперь честно сообщает `bodies, ships, facilities, populations, markets` только для нового флота.
5. Сохранение: `N39.snapshot` уже сохраняет весь авторитетный world+ledger; N158 нормализует safe whole-integer поля ship wallets, cargo counts, N14 transit last_tick/departure_tick/arrival_tick/token, ship_next_token. Legacy saves **без ships** загружаются без автопересоздания/полного заправления (в них fleet feature остаётся выключен). После успешного restore volatile ship event сбрасывается. N38 filesystem checkpoint остаётся единственным.
6. `observer_panel.gd` / `main.gd` показывают **реальные** 24 ships, классы и ship in transit/fuel в одном read-only observer. `star_system_view.gd` показывает у планет только корабли, фактически находящиеся у станции, а не стартовые статичные 8 маркеров, и **не рисует несуществующие координаты полёта на схематичной карте**.
7. Новый локальный тест `godot/tests/p2_unified_ship_phase_check.gd`: 24 оригинальных ship IDs и 3×8 faction, source credits в общем N9, полный N46 fuel/empty cargo, invalid-route fail-closed, directed Earth→Alpha N14 flight, 5 реальных тиков, true fuel decrease, signed transit nonce, сохранение N38 file, restart and next 5 ticks; прежний `p2_n158_live_production_check.gd` обновлён на честную фазовую декларацию.
