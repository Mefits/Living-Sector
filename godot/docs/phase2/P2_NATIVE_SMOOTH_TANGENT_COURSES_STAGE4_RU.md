# Living Sector · Этап 4: настоящие плавные обходные траектории N14

**Дата:** 17 ноября 2026. **Рабочая ветка:** «Баланс Системы» (`feature/SystemBalance`).
Исходные Rust Galaxy 0.6.7, «Текущая» и «5 рабочих с Астрой» не изменены.

## Проблема

Предыдущий `native_avoidance.gd` рисовал фактический маршрут
с несколькими угловатыми радиальными точками. N14 расходовал **один
полный тик и топливо на прохождение каждого короткого участка**:
это особенно ломало движение вокруг планет с реальными радиусами
в десятки тысяч раз меньше расстояний между планетами.

## Изменения

- `NativeAvoidance.plan()` теперь строит **две геометрически
  допустимые касательные** к внешней безопасной окружности и
  выбирает кратчайший по угловой дуге маршрут, если он физически
  проходим. Вход и выход на дугу касательные, без прямого резкого
  излома. Окружность приближена реальными короткими хордами
  с угловым шагом максимум 15°; не более **24 точек на рейс**.
  Это настоящие координаты движения N14, не экранная
  искусственная кривая. Данные сохраняются в N39 `transit`.
- Сравнение длины двух касательных путей делается **аналитически**;
  рассчитывать обе дуги полностью не нужно: сначала проверяется
  кратчайшая, противоположный вариант проверяется только
  при её непроходимости. Это ограничивает стоимость
  расчёта при массовом одновременном вылете.
- `ShipTransit.advance()` теперь расходует **один общий бюджет
  физического пути за тик** на последовательное прохождение
  нескольких близких хорд. Цикл строго ограничен 24 отрезками.
  Топливо оплачивается ровно один раз за действительный
  fired-ход. Никаких дополнительных корабельных тиков,
  свободных перемещений или мгновенных переносов.
  Сохранён `physical_distance_travelled` и право N140
  определять частоту исполняемых шагов.
- Перед каждым настоящим отрезком проверяется наличие звезды
  или подтверждённого физического планетного препятствия
  в текущем снимке. При блокировке до начала движения —
  безопасный `holding`, без списания топлива;
  если за этот же тик уже была часть безопасного пути,
  она оплачивается и сохраняется, а новая опасная часть
  не выполняется.
- **Последний шаг к цели** теперь проверяется по
  актуальной физической N43-координате цели, а не только
  по упреждённой точке; это исключает скрытый сквозной
  перелёт, когда дистанция до цели уже меньше одного
  шага N14.
- Карта показывает ограниченное число настоящих сохранённых
  точек **только у выбранного корабля**, а не
  500 траекторий одновременно.

## Реальные тесты Godot 4.7.2

`p2_smooth_n14_navigation_check.gd` доказывает
плавность перехода между касательным участком и
хордами; отсутствие пересечения радиуса препятствия;
прохождение нескольких точек за один такт в пределах
одного velocity; один реальный расход топлива;
сохранение/загрузку N39-подобного состояния; достижение
реальной цели без телепортации; пересечение малых
физических радиусов не игнорируется. Специальный случай
короткого, на один тик, опасного сближения показывает,
что даже при расстоянии до цели меньше скорости,
корабль не объявляет прибытие сквозь звезду.

Дополнительно обязательны старые тесты:
`p2_native_navigation_check.gd`,
`p2_moving_planet_avoidance_check.gd`,
`p2_n14_nav_500_check.gd`,
`p2_ship_scale_500_benchmark.gd`,
`p2_native_orbital_intercept_check.gd`,
`n14_transit_check.gd`,
`n43_native_location_resolver_check.gd`,
`p2_unified_ship_phase_check.gd`.

**Ограничения:** это плавные реальныe *обходные* дуги с
касательными, **не универсальные эллиптические
гравитационные орбиты**. Свободные межпланетные
перелёты без препятствий используют прежний
упреждающий курс. Экономика, ускорение / торможение
и локальные скорости ещё требуют совместной
балансировки игрового календаря. 500 N14 полётов
в тесте являются тестовой группой внутри корабельного
модуля; полноценная экономика, AI, 50+ систем,
10k+ тиков при ×16 на Windows здесь пока не
доказаны.
