# N24 — read-only диагностика P1

Источник: frozen Rust `native/crates/sim_core/src/agents/ship/snapshot.rs`: snapshot строится из авторитетных компонентов, а не управляет ими. В P1 доступен только орбитальный writable state; этот блок не имитирует снапшоты экономики, AI или транспорта.

`diagnostic_snapshot.gd` строит детерминированную проекцию: идентификаторы систем/тел/предприятий, ориентированные рёбра маршрутов, численность известных seed-коллекций, текущие углы орбит, tick и явный список проблем. Чтение только через копии `world.worlds()` / `world.factions()` / `orbital_snapshot()`; никаких изменений модели. Дубли проверяются в пределах категории. Стабильная сортировка списков не зависит от порядка обхода Dictionary.

`godot --headless --path godot --script res://tests/n24_diagnostic_check.gd`

Тест проверяет повторяемость, отсутствие мутации, 8 систем/3 фракции/47 тел, изменение углов после тиков и точное совпадение диагностики после checkpoint restore. Не выполнялся без Godot Runtime: **CODE_UNVERIFIED**.

Зависимости: P1-A (PR #87); N4 registry PR #92 не требуется для запуска, его полный каталог будет интегрирован отдельно. Диагностика не является форматом сохранения и не заменяет native Rust ShipSnapshot.
