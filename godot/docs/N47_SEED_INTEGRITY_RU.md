# N47 — независимая проверка целостности native seed

Новая read-only preflight-проверка `scripts/sim/seed_integrity.gd` принимает только словарь уже загруженного Galaxy 0.6.7. Не создаёт сущности, не исправляет данные, не запускает экономику и не меняет `NativeData`/старые сохранения.

Проверяет: уникальность ID систем/фракций/тел/предприятий, обязательные массивы, конечные координаты, допустимые орбитальные периоды и углы, владельцев кораблей/предприятий, направление/дистанцию маршрутов, ожидаемые 8 систем/3 фракции/47 тел/15 предприятий/24 корабля/3 рынка/3 населения. Отчёт сортирован и повторяем, без side effects. Режим `enforce_reference_counts=false` разрешён только для изолированных тестовых миров, не для эталона.

Границы: это дополнительный инспектор, **не подключён** к запуску игрового мира, не доказывает паритет движения, экономики или ИИ. Маршрутные endpoints могут быть именами навигационных объектов, поэтому здесь не предполагается их принадлежность к ID тел. Для них используется существующий `route_graph.gd`. Встроенные Godot `Dictionary`, `Array`, `JSON` и `RefCounted`; сторонних зависимостей/лицензий нет.

Smoke: `godot --headless --path godot --script res://tests/n47_seed_integrity_check.gd`. Тест сравнивает эталон и четыре копии с намеренными повреждениями; не пишет в пользовательские сохранения. Пока Godot Runtime не запущен — CODE_UNVERIFIED.

Источник: `archive/rust-galaxy-067-reference`, `native/priv/galaxy/data`, существующий `scripts/native_data.gd` и `world_model.gd`. Никаких новых игровых формул.
