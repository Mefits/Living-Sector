# N34 — надёжность интеграционной приёмки Godot

Статус: **CODE_UNVERIFIED**. Ветка основана на N33 PR #121, который основан на N32 PR #120. Это исправления тестового инструмента, не перенос новой Rust-механики и не доказательство runtime parity.

## Обнаруженные риски N33

1. Повторное использование каталога `logs/integration-acceptance` позволяло старому `*.log` влиять на новый запуск и даже скрывать отсутствие свежего лога.
2. `Start-Process -Wait` не имел ограничения времени; зависший GDScript блокировал приёмку.
3. Нулевой код процесса при отсутствии созданного Godot-лога мог быть записан как PASS.
4. Нет отдельного контроля количества реально выполненных процессов относительно выбранного набора.

## Реализация

- В начале каждого запуска удаляются **только обычные файлы** в специально выделенном каталоге логов N33; исходники, сейвы и другие журналы не трогаются.
- Каждая команда Godot получает таймаут (по умолчанию 90 секунд); зависший процесс завершается с FAIL/124. Параметр `GODOT_SMOKE_TIMEOUT` можно задать для CMD, допустимо 10–600 секунд.
- Для PASS требуется свежий файл Godot `--log-file`, нулевой код и отсутствие ERROR-маркеров в stdout/stderr/log.
- Приёмка fail-closed проверяет наличие каталога tests, обязательных quick-тестов и точное число записей об импорте и выполненных тестах.

## Короткая приёмка на Windows

1. Запустить `godot/RUN-INTEGRATION-ACCEPTANCE.cmd` и проверить `logs/integration-acceptance/summary.json`.
2. Запустить `godot/RUN-INTEGRATION-ACCEPTANCE.cmd all` и проверить, что число запусков соответствует обнаруженным тестам плюс импорт.
3. Проверить отсутствие Godot.exe: код 2, `summary.json.status=FAIL`.
4. Установить `GODOT_SMOKE_TIMEOUT=10` и намеренно запустить зависающий тест **только в отдельной тестовой копии**: FAIL/124, процесс не остаётся висеть.
5. Повторить запуск после неудачи: старые логи не должны попадать в новый результат.

Проверки в агентской среде: сопоставление изменённых строк и статический анализ сценариев; Godot/Windows PowerShell отсутствуют, **реальный запуск не выполнялся**. До Godot runtime статус VERIFIED запрещён. Экономика, логистика и ИИ в авторитетном TickRunner N32 не считаются интегрированными.
