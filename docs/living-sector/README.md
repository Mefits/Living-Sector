# Living Sector — рабочая документация

**Дата переноса:** 2026-11-03. **Основа:** публичный форк [The Space Project](https://github.com/Kalcode/spaceprojectsim) (Rust + Bevy). **Статус:** проектирование собственной игры/симулятора, без наших изменений механик.

## Что мы делаем

Наша текущая цель — развить автономную симуляцию космического сектора с экономикой, фракциями, логистикой, исследованиями, конкуренцией за объекты и сохраняющейся историей мира. **Основной интерфейс будет нашим собственным полноэкранным 2D-стратегическим наблюдателем**, с картой наподобие Stellaris, территориями фракций и режимами просмотра. Исходный 3D-клиент используем как инструмент проверки симуляции, а не как шаблон итоговой игры. Сектор должен существовать и изменяться без участия игрока.

При этом **идея личного управления персонажем НЕ отменена**: позже может появиться режим посещения кораблей и станций с глубокими взаимодействиями в духе Space Station 13. Сейчас это долгосрочное направление, не предмет первой реализации.

## Источник истины

Для **реально работающих механик** источником истины является код репозитория и проверки на конкретном коммите. Для **предпочтений владельца** — VISION/DESIGN. Старые Godot-файлы, ранее подготовленные для отдельного концепта, не должны копироваться поверх структуры Rust/Bevy.

Используем статусы: **согласованное направление**, **предпочтение**, **предложение**, **вопрос**, **проверено**, **не проверено**. «Согласованное направление» ещё не означает окончательную реализацию.

## Текущая граница работ

Сначала сохранить пригодность исходной симуляции и получить воспроизводимый baseline. Затем выбрать границу между ядром и новым UI и создать отдельный режим Strategy/Observer. Прежняя `Sector`-панель в экспериментальном PR #1 — не окончательный интерфейс. Далее экспериментировать с новыми системами. Не начинать с переписывания существующей экономики.
