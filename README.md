# Living Sector — Genesis Clean 0.5

Небольшая самостоятельная версия симулятора с 2D-картой в браузере.

## Запуск на Windows

1. Распакуйте архив в папку, в которую можно записывать файлы.
2. Запустите `Start-Genesis.cmd`. Если вкладка не открылась, откройте адрес, который появится в окне программы.
3. На карте нажмите «Продолжить». Первый груз в 50 единиц руды прибывает примерно через 32 секунды на скорости 1×.

Снабженец запрашивает 50 руды по целевому запасу и потребности плавки. Установка готовит партию по заявке. Перед вылетом грузовик проверяет запас топлива на оба перелёта. Плавка расходует 10 руды и 1 топливо на 8 металла. Когда склад металла заполнен (80 единиц), плавка останавливается. У причала он виден в списке станции или установки. В полёте он появляется на карте. В верхней строке видны запасы на обоих складах и в трюме. Топливо расходуется на перелёты, а местные резервы ограничены.

Состояние записывается рядом с EXE в `genesis-clean-v1.json`. Версия 0.5 читает сохранения 0.1, 0.3 и 0.4. При следующем запуске симуляция открывается на паузе. Для нового мира закройте программу и переместите файл сохранения из папки.

## Политика фракции

На карте откройте «Фракция». Сводка показывает курс, резерв и работу администраторов. Осторожный глава меняет курс после двух секунд при 194 топливе или ниже, промышленник — при 190 или ниже. Новый мир начинается с 200 топлива станции. По умолчанию новый мир возглавляет промышленник. Для осторожного главы задайте `set GENESIS_LEADER=cautious` перед запуском нового мира. Для отдельного файла используйте `GENESIS_SAVE_PATH`.

## Стройка и первый конфликт

Стартовый сценарий включает по одному строителю на фракцию. Строитель Genesis привозит на площадку 16 металла для верфи и 8 для первого грузовика. После налёта он может привезти ещё 8 металла для патруля. В начальный комплект Genesis включены 12 единиц топлива строителя и 12 единиц топлива для ввода двух корпусов в строй. Пиратский строитель начинает на площадке с привезёнными 16 металла и 6 топливом для рейдера. Месторождение Genesis содержит 500 руды. Трофеи хранятся на пиратской базе после возвращения рейдера.


## Сборка из исходников

Нужен Rust 1.95 или новее. Команда `cargo build --locked --release` собирает приложение со встроенной картой. Сервер по умолчанию слушает `127.0.0.1:17860`. Порт можно изменить через `GENESIS_PORT`, путь сохранения через `GENESIS_SAVE_PATH`.

Один сценарий проверки запускается командой `node tests/ore-loop.mjs <путь-к-бинарнику>` (Node.js 22+).
