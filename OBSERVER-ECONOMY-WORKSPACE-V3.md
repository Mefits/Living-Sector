# Observer Economy Workspace V3

Это **самостоятельный сайт-проект** для согласования интерфейса; реальный Observer V5, игровая экономика, AI, API и SQLite не изменены.

- Главный вход: [index.html](./index.html) (автономный HTML; все CSS и JS внутри).
- Выбор 3 станций Genesis (Sol/Alpha Centauri).
- Отдельные окна: станция, склады, предприятия, сигналы, персонал, процессы и аналитика.
- Два режима раскладки: сетка и перемещаемые окна, пользовательские настройки сохраняются локально.
- Импорт `/api/report` JSON или только GET по API. Никаких управляющих запросов.
- Ориентир запаса 5000 — **условный масштаб интерфейса**, не фактическая вместимость хранилища. Скорости, эффективность и прогресс производства не моделируются. Реальный прогресс стройки и trend_samples выводятся только при наличии полей API.
- Карта в этом статическом сайте схематическая; реальная карта Observer V5 остаётся в приложении.

## Публичная ссылка через GitHub Pages

1. Repository **Settings → Pages**.
2. **Build and deployment → Deploy from a branch**.
3. Branch: `prototype/observer-economy-workspace-v3`; Folder: `/(root)`; **Save**.
4. После успешной публикации зайдите на URL из GitHub Pages (обычно `https://mefits.github.io/Living-Sector/`, но до активации сайт по нему **не существует**).

Ветка изолирована от `integration/genesis-unified-20261107` и PR #40. Чтобы обновить сайт, вносите изменения в `index.html` этой ветки.
