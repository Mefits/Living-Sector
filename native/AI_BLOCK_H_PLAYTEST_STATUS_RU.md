# Living Sector — Block H: наблюдение за нативным ИИ в игровом интерфейсе

**Основа:** исходники блоков A–G. Block G/FIX2 ещё не проходили проверку Rust у пользователя, поэтому Block H — не подтверждение корректной сборки и не доказательство автономности.

## Что добавлено

- `GET /api/strategy` уже отдаёт поле `ai_execution` из сохранённого `Director`. Ранее Observer молча его отбрасывал при разборе API. Теперь `observer/strategy-model.js` сохраняет это необязательное поле; прежний API v1 поддерживается.
- В подробном **инспекторе стратегии** (`/observer/native.html`) показываются активная цель/алгоритм/шаги, нативный ID заказа, фактические квитанции, причина ожидания, отложенная цель и история завершённых планов. Никаких новых серверных команд.
- На главной странице `/observer` показываются краткое состояние текущего плана, отложенные цели и последние результаты. ИИ можно наблюдать непосредственно в Galaxy, без чтения JSON.
- Вывод отличает `submitted` от `succeeded`. Показ «цель подтверждена» требует причины `native_receipts_and_goal_stock_confirmed`, реального `observed_goal_stock >= target_units`, и успешных шагов с `native_order_id`. Без данных честно написано «нет доказательств».
- `PLAY-HYBRID-GALAXY.cmd` **всегда собирает актуальный Rust** и запускает его с `LIVING_SECTOR_PLANNER=hybrid`, портом 18081 и отдельной БД `ai-hybrid-gameplay.db`. Не переписывает штатную Galaxy.
- `PLAY-HYBRID-WATER-TEST.cmd` создаёт первоначальные условия лёд → доставка → завод → вода в отдельной копии семени, запускает отдельную БД `ai-hybrid-water-gameplay.db` на порту 18082. Тестовые ресурсы выдаются исключительно до запуска сервера, не во время игры.

## Проверено в доступной среде

- 55/55 тестов Observer (включая 3 новых теста нативного состояния/квитанций/UI).
- 10/10 тестов Python-инструментария.
- `node --check` всех изменённых JS, включая inline-сценарий в `observer/galaxy.html`, успешно.
- `observer/build-strategy.mjs --check` — сгенерированный серверный UI совпадает с источниками.
- **Не проверено:** Rust компиляция блоков FIX2/G, фактическая доставка льда и вода в новом Windows-сервере. Первый запуск `PLAY-HYBRID-*.cmd` будет компилировать текущий исходный код.

## Первое игровое испытание (когда готовы компилировать)

1. Распаковать архив в **новую папку**. Запустить `PLAY-HYBRID-WATER-TEST.cmd` (потребуются Rust/Cargo и Python). Он соберёт сервер и откроет настоящую Galaxy/Observer; использует отдельные данные и БД.
2. В главной панели выбрать землян; смотреть **«ГИБРИДНЫЙ ИИ / НАТИВНЫЙ ПЛАН»**. Для подробностей открыть «Инспектор» → «Стратегия фракций» → **«HTN / GOAP / BEAM · ИСПОЛНЕНИЕ»**.
3. Не считать демонстрацию успешной, пока не видны `succeeded` для доставки и завода плюс подтверждённый запас воды. Если это не произошло — это диагностический результат, а не успешный тест ИИ.
4. Отдельно `PLAY-HYBRID-GALAXY.cmd` запускает нормальную исходную Galaxy без искусственных стартовых запасов, но всё ещё на отдельной БД.

**Весь игровой цикл будет доказан только после реальных квитанций нового скомпилированного сервера.** В текущем коде гибридная интеграция ограничена снабжением/производством; долгосрочные исследования, строительство и колонизация по-прежнему управляются штатным директором.
