# Living Sector Galaxy 0.6.7 — бесплатная локальная сборка и игровая проверка

**Откуда:** экспериментальная ветка `integration/galaxy-067-unified-playtest` (PR #83). В неё уже входят PR #76–82. Основную стабильную ветку и пользовательские сохранения эти скрипты не изменяют.

## Запуск на Windows (без GitHub Actions)

1. Скачайте [полный ZIP экспериментальной ветки](https://github.com/Mefits/Living-Sector/archive/refs/heads/integration/galaxy-067-unified-playtest.zip) и распакуйте его в папку с доступом на запись.
2. Откройте папку **native**.
3. Дважды щёлкните **PLAYTEST-GALAXY-067-LOCAL.cmd**.
4. При отсутствии Rust скрипт **сначала спросит разрешение**, и только после ответа `y` бесплатно загрузит компилятор с официального сайта Rust в `native/.local-galaxy-rust-tools/`. Не требует прав администратора и не меняет системный `PATH`.
5. Если реальная сборка и короткий запуск пройдут проверку, в папке `native/local-playtest-results/run-.../` появится **Living-Sector-Galaxy-067-Win64.zip**. В распакованной папке запустите **START-GALAXY.cmd** — он откроет игру в браузере на `http://127.0.0.1:18067/observer/`.

Это **тестовый** архив, не обновление stable. Игра использует отдельную новую базу `galaxy-067-experimental.db`, прежние миры не перезаписывает. Режим ИИ по умолчанию — нативный Director, HTN остаётся опциональным.

### Что проверяется

Одна сборка настоящего `sim_server` и один ограниченный запуск сервера с данными Galaxy (восемь систем и три фракции), API `/api/strategy` и `/api/report`, HTTP-пути Observer, передача настоящего экономического поручения **Hold** и его отображение в решении Главы. Проверяется наличие пятиэтапной цепочки строительства, если сервер её возвращает. Проверка **не требует полного строительства мегаструктур или прогона экономики на годы**.

Создаётся `RESULT.json` и небольшой **Living-Sector-Galaxy-067-DIAGNOSTICS.zip** с логами. В него **не включаются** сохранения, личные файлы и бинарный кэш компилятора. Именно этот небольшой ZIP можно прислать в чат при ошибке.

Для новой временной SQLite выполняется проверка **заголовка**, а не полный `PRAGMA integrity_check`. Старые пользовательские SQLite и Windows-совместимость сохранений этим тестом не проверяются.

### Если сборка не запускается

Rust — бесплатный, но сборка Windows/MSVC может дополнительно потребовать установленные **Visual Studio C++ Build Tools и Windows SDK**. Скрипт их скрыто не устанавливает. Если компиляция не удалась, откройте `build.stderr.log` в последней папке результатов или пришлите диагностический ZIP. Если нет желания скачивать компилятор, ответьте `N` на запрос — файлы проекта останутся нетронутыми.

**Никакой оплаты GitHub не требуется.** Нулевой бюджет GitHub Actions менять не нужно. Сборка и тест идут только на вашем компьютере.
