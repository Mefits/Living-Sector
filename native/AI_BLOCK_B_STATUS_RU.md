# Living Sector AI — Block B: подготовлен код GOAP + Beam

Основа: Block A, уже подтверждённый пользователем (`cargo check`, 27 planning, 6 coordination, 7 station, сборка server). **Не приписывать эти результаты новому блоку B.**

## Реализовано в исходниках

- Адаптер `TelicGoapAdapter`: использует оригинальную библиотеку Telic 0.1.0 для символического GOAP-ориентира, **обязательно** проверяет ресурсы и деньги точным поиском.
- Адаптер `ControlBeamAdapter`: ширина 16, общие с HTN состояние и действия, ограничение узлов/глубины.
- Общий безопасный прогнозный домен переиспользован из HTN без нового игрового мира.
- `compare_planners`: HTN, GOAP и Beam по одному снимку, единый валидатор, диагностический JSON; не ранжируем native baseline некорректной метрикой.
- Опциональная диагностика по `LIVING_SECTOR_PLANNER_SHADOW=1` + `LIVING_SECTOR_PLANNER_COMPARE=1`. По умолчанию выключено; нативный контрактный исполнитель блока A не менялся.
- Пять новых модульных проверок + CLI-пример, JSON-fixture, один CMD-пакет проверок.

## НЕ проверено / ограничения

- **Новый Rust-код НЕ скомпилирован в этой среде**. Вся новая функциональность ожидает Rust/Cargo-теста; ошибки компиляции или зависимости Telic возможны.
- Новый Windows EXE не запускался, реальных игровых испытаний GOAP и Beam не было.
- Нативное исполнение существует только для opt-in HTN блока A; GOAP/Beam — пока анализ и сравнение.
- Telic GOAP применяется для структурного направления exact search; это не полноценный общий гибрид и не чистое количественное GOAP библиотекой Telic.
