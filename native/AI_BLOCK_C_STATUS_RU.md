# AI Block C — краткая передача

**База:** Block B из `LS-AI-BlockB-SOURCES.zip` (исходники B всё ещё не скомпилированы пользователем).

**Готово в исходниках:** `HybridPlanner` — Utility/Personality из директора выбирает цели; HTN 0.2.1 декомпозирует; GOAP/Telic 0.1.0 может решать фактическую подзадачу снабжения перед HTN-производством; Beam вызывается только при альтернативных путях или отсутствии решения. Тот же безопасный нативный исполнитель Block A выбирается через `LIVING_SECTOR_PLANNER=hybrid`. Модель склада/денег и механизм сохранения не заменены.

**Проверено здесь:** 13/13 Node-тестов Observer, баланс скобок в изменённых Rust-файлах, комплектность исходников и архив ZIP. **Не проверено:** компиляция Rust B/C, запуск нового сервера, реальное выполнение гибридных приказов. Нельзя считать этот блок работающим только по имеющемуся коду.

**Тебе нужен один запуск:** `VERIFY-AI-BLOCK-BC.cmd` → `AI-BLOCK-BC-RESULTS.zip`. Установка Rust уже есть. В тест входят B и C, поэтому отдельно B запускать не надо.

**Для следующего исполнителя:** подробности в `docs/living-sector/AI_BLOCK_C_HYBRID_RU.md`. При ошибке Cargo сначала починить именно сборку и целевые тесты, не расширяя игру. При успехе следующий этап — ограниченный реальный сценарий доставки/производства/квитанций и сравнение baseline / HTN / hybrid по одинаковому состоянию.
