# Каталог из 36 возможных стратегических целей

Дата: 2026-11-05. **Предложение**, не 36 реализованных обработчиков и не перечень
обязательного содержания первого релиза. Контекст — [аудит](ASTRA_ARCHITECTURE_REVIEW.md).

Цель описывает желаемое состояние и причину интереса. Проект выбирает способ его
достичь, задача — конкретного исполнителя. «Построить три завода» здесь не цель.
К/В — предложенная обычная роль ключевой/второстепенной цели; глава вправе менять
роль по обстоятельствам, например поднять резерв топлива до ключевого при кризисе.

Готовность: **A** — есть подходящие исполнители, но нужны исправления P1 и адаптер
управления; **B** — есть часть механики, требуется предметное расширение;
**C** — будущий домен, сейчас выполнение запрещено отсутствием capability.
Ни одна отметка A не означает, что автономный глава уже работает.

## Выбранный первый набор для эксперимента

Кандидаты 01, 03, 04, 19, 20 и 23, но только небольшой совместимый портфель.
Первый сквозной проект — 03/19: глава хочет восстановить полезный выпуск,
промышленный администратор выясняет нехватку входа, логистический выбирает
доставку, перевозчик выполняет реальный контракт, recipe подтверждает эффект.

Ключевой отрицательный вариант: нет доступного источника или средств/топлива —
проект блокируется и пересматривается. Цель 11 не должна автоматом порождать новую
фабрику, пока существующая простаивает. Цель 07 остаётся ограниченной доступными
модулями/перевозками; отсутствие hull build не скрывается.

Отделять желание и способ: `organize_convoys` может быть второстепенным направлением
безопасной логистики; конкретные суда/дата сбора — уже проект. Если в эксплуатации
оно всегда оказывается только методом другой цели, убрать отдельный GoalDefinition
и оставить capability. Каталог подлежит сокращению по таким наблюдениям, а не
сохраняется ради числа 36.
