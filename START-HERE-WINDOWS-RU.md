# Living Sector — Windows Godot 4.7.2 preview

Это **цельный снимок проекта** на ветке `fix/godot-n32-diagnostics-20261112`, а не набор отдельных патчей.
Основа: N32 PR #120 + Windows/4.7 исправления PR #122. Эталонный Rust не менялся.

## Один запуск — без ручных проверок по одному файлу

1. Скачайте ZIP **всей ветки** и полностью распакуйте (важно сохранить соседнюю папку `native/priv/galaxy/data`).
2. Положите ваш уже скачанный **Godot 4.7.2 Standard** под именем `Godot.exe` в папку `godot`. Если Godot доступен в PATH или в переменной `GODOT_EXE`, копировать не надо.
3. Дважды щёлкните **`PLAY-LIVING-SECTOR-WINDOWS.cmd` в корне проекта**. Он делает один импорт и сразу запускает игру. Все 11 smoke-тестов вручную запускать не требуется.
4. Если не открылось, отправьте **один ZIP с папкой** `godot/logs/startup` (либо при ошибке импорта только `import-console.txt`). Не надо собирать/перекладывать файлы вручную.

Важно: локальные сохранения и профили Godot находятся отдельно; новый архив не изменяет старую папку, если распаковать рядом. Не помещайте в ZIP личные сейвы или токены.

## Что фактически подтверждено

По Windows-логам Godot 4.7.2:
- 10/11 быстрых отдельных тестов проходят (по результату скрипта)
- после правки `ObserverProjection` импорт проекта проходит без зафиксированного в прежнем логе конфликта `Projection`
- один тест N31 не загружал `ship_state.gd` / `contract_board.gd`; после этого был исправлен конфликт зарезервированного параметра `class_name`, но повторная проверка этих двух зависимостей **ещё не подтверждена**
- это НЕ полная проверка ИИ, экономики, логистики или полного переноса Rust

Кнопка запуска предназначена для проверки видимого игрового экрана, а не для заявлений о завершённом переносе. PR #122 остаётся Draft; main/stable не затронуты.

## Ручная приёмка P1 на Windows — 2026-11-12

**Подтверждено пользователем на реальном Godot 4.7.2 Standard:**

- Полная ветка в ZIP распакована локально, `Godot.exe` установлен в папку `godot`.
- Игра **успешно запущена** и показывает настоящий экран Godot (не HTML): карту систем, центральный инспектор и наблюдателя N20.
- На экране отображаются **8 систем, 3 фракции, 47 тел**; счётчик дошёл до тика **323**, в момент снимка игра на паузе.
- Пользователь отдельно подтвердил: при выборе другой звёздной системы центральная панель **меняет данные**. Интерактивная карта P1 принимается как работающая вручную.

**Не подтверждено этой приёмкой:** корректность работы сохранения/загрузки по содержимому, паритет орбит с Rust на длительном горизонте, полноценные фазы экономики/торговли/кораблей/контрактов/ИИ, N31 после последних исправлений, скорость и производительность при ×16. Наличие кнопки не означает проверку функции. В базовом `TickRunner` реально выполняется только фаза `bodies`.

**Решение:** зафиксировать этот commit как **первый вручную запускаемый Godot P1 Preview / UI acceptance**, но НЕ как готовую симуляцию и НЕ сливать без дальнейшей интеграционной проверки. Для дальнейшей разработки использовать один полный ZIP/ветку на этап и один запуск, без серии индивидуальных CMD-патчей для пользователя.
